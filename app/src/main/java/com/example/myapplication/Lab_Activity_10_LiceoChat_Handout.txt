1  ·  What You Will Build
You will build LiceoChat, a small chat app for this class. Everybody in the room talks to the SAME server, so the messages you see on your phone are the messages your classmates are typing right now. When you send a message, it appears on their screens too.
There is one screen. It has three parts:
• A list of messages - who sent it, what they said, and when. Newest at the top.
• A text box and a Send button at the bottom of the screen.
• A Refresh button in the top bar, so you can pull the newest messages.

WHY THIS APP  Everything you will write today is what you did in the lecture, in the same order: a data class for the JSON, a Retrofit interface, a repository that returns a result instead of throwing, a mapper, and a screen with four states. The only new thing is that you will also SEND data, not just read it.
The four screen states you must handle
StateWhen it happensWhat the user must seeLoadingWhile the app is fetching messages.A spinner in the middle of the screen.ReadyMessages came back.The list of messages, newest first.EmptyThe call worked but there are no messages yet.A friendly line such as "No messages yet. Say hello!"ErrorNo internet, a timeout, or the server failed.A short message AND a Retry button.
CAREFUL  "No messages" is NOT an error. It means the call succeeded and the list was empty. If you show the error screen for an empty list, you lose points - and your users get confused.2  ·  What You Are Practising
By the end of this activity you should be able to:
1. Write a @Serializable data class that matches a real JSON response, using nullable fields and default values.
2. Declare a Retrofit interface with @GET, @POST, @Query and @Body, and build the Retrofit instance correctly.
3. Write a repository that catches network exceptions and returns a named result instead of crashing.
4. Write a mapper that turns the server's class (DTO) into your own clean class.
5. Build a Compose screen that draws all four states and lets the user send a message.

package com.liceo.liceochat.core
 
sealed interface AppResult<out T> {                 // GIVEN (read it, do not change it)
 
    data class Success<T>(val data: T) : AppResult<T>
 
    sealed interface Failure : AppResult<Nothing> {
        data object NoInternet : Failure
        data object Timeout    : Failure
        data class  Unknown(val message: String?) : Failure
    }
}

What you seeWhat it meansWhat to dobaseUrl must end in /Your BASE_URL has no slash at the end.Add the slash.404 on a URL that works in the browserYou wrote @GET("/messages") with a slash in front.Remove that slash.SecurityException: Permission deniedThe INTERNET permission is missing.Add it to AndroidManifest.xml (step A3).CLEARTEXT communication not permittedYour address starts with http://Use https:// instead.Serializer has not been found for typeThe class has no @Serializable, or the plugin is missing.Add the annotation; check the plugins block.Expected start of the arrayYou returned MessageDto instead of a list.Change it to List<MessageDto>.Field 'sender' is required but it was missingYour DTO field has no default value.Make it nullable with = null.NetworkOnMainThreadExceptionA function is missing the word suspend.Add suspend to the interface functions.The app compiles but the list is always emptyThe base URL is wrong, or the sort parameters are misspelled.Read the URL printed in Logcat by OkHttp.An empty screen and no error at allYou did not handle every branch of the when.Check TODO 9 covers Success, NoInternet, Timeout and the else.You cannot see anyone else's messagesYou are pointing at the wrong address.Compare your BASE_URL with the board, character by character.Unresolved reference: viewModelA Compose import is missing.Press Alt+Enter on the red text and let Android Studio add it.
